import math

def limit_mag(aperture_mm: float) -> float:
    """估算口径对应的极限星等"""

print(limit_mag(150))  # 约 14.1 等
```

## 观测建议

> 星等每相差 1 等，亮度相差约 **2.512 倍**。市区极限星等往往只有 3~4 等，建议优先选择上表中 ==视星等 ≤ 5== 的目标。

### 春季

- M51 与 M101：大视面星系，需要较暗的天空
- M13：北天最壮观的球状星团之一

### 夏季

- M57：高倍下呈明显的环状
- M27：比 M57 更亮的行星状星云

### 秋季

- M31：肉眼可见的最远天体（约 254 万光年）
- M33：面亮度低，务必避开月光

### 冬季

- M42：冬季星空的主角，流程参见 [[观测者手册]]
- M45：双筒镜中最璀璨的疏散星团

### 暗适应

视网膜杆状细胞在黑暗中逐步提高感光灵敏度的过程，完全建立约需 `20~30` 分钟。适应期间应只使用 ==红光== 照明。

### 视宁度

大气湍流导致星像抖动的程度，常用 `I~V` 级表示。视宁度差时，高倍观测毫无意义。

### 极限星等

肉眼或仪器可见的最暗星等。市区肉眼约 3~4 等，暗夜郊外可达 6.5 等左右。

### 出瞳距离

目镜成像到人眼的最佳距离。戴眼镜观测者应选择出瞳距离 ≥ `15mm` 的目镜。

### 最后确认

请确保你的 **`js/app.js`** 用的是我上一条消息给你的那份（条目页外壳版），而**不是** `home.js` 的内容。两个文件的内容必须不同：

- `home.js`：首页用，负责项目卡片 + 终端打字
- `app.js`：条目页用，负责侧边栏 + Markdown 渲染 + 大纲 + 翻页

改完后 `Ctrl+Shift+R` 强制刷新。
